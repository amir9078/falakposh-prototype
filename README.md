# Falakposh storefront prototype

Live preview: https://amir9078.github.io/falakposh-prototype/ (GitHub Pages, served from the `gh-pages` branch)
Private copy (first, navy version, not updated): https://claude.ai/artifact/N8J1qhEz1PmbmjjxATTL6m

A static prototype of the Falakposh store. It is laid out so each template maps onto a Shopify theme section later.

## Build and preview

```
"%LOCALAPPDATA%/Python/pythoncore-3.14-64/python.exe" build.py            # pages only
"%LOCALAPPDATA%/Python/pythoncore-3.14-64/python.exe" build.py --images   # also re-cut every photo
```

- Output goes to `dist/`, which is committed. The original photos live outside this repo (`../_img_src/full`), so `--images` only works on the machine that has them.
- Publish to GitHub Pages: `git subtree split --prefix dist -b gh-pages` then push `gh-pages`.
- `dist/_artifact_index.html` is the home page without its document wrapper, for publishing as an Artifact.
- Local preview: the `falakposh-proto` server in `.claude/launch.json` (port 8190).
- Screenshots: `node _review/capture.mjs <outDir> page.html [--dark] [--sections] [--size=desktop|mobile]`. Start headless Chrome on port 9334 first if the script can't open it.

## Identity (second redesign, 7 Oct 2026)

- **Palette, Jamun** (chosen 7 Oct 2026, live): blush white `#F8F2EF`, panels `#EFE3DF`, ink `#2A1626`, jamun plum `#5C2148` for buttons and accents, rose gold `#B07E6C` for the star, hairlines and the seal (deepened from the presented `#C09684` so gold Urdu and focus rings reach 3:1). The night band and intro are `#1D0F19`; dark mode uses a dusty mauve `#C897B0` accent. `identity.html` keeps Laal (red) and Firozi (teal) for reference.
- **Logo**: real Nastaliq calligraphy, not live text. `../../brand/calligraphy/build_logo.py` takes Gulzar glyph outlines shaped by HarfBuzz (`shape.html` writes `glyphs.json`), replaces the dot of fa with a zari star, and writes `templates/partials/logo.html` (mark, stacked, lockup, seal) plus static SVGs in `../../brand/logo/svg/`. Do not edit `logo.html` by hand. PNG exports and the Instagram avatar are in `../../brand/logo/`.
- **Logo motion** (`static/js/logo.js` + the `.fp-logo` block in `site.css`): the letters are written right to left as a calligrapher would (gold trace, then ink), the dots land, the star falls in as the dot of fa, then FALAKPOSH settles. It plays once per session as an intro curtain on the home page (any tap skips it), in the footer and on the identity page when scrolled into view. The header star twinkles now and then and on hover. Nothing moves under reduced motion.
- **Type**: Bodoni Moda for names and titles, Gulzar for Urdu names, Noto Nastaliq Urdu for small Urdu, Jost for labels and body.
- **Photos**: `data/images.json` sets each photo's focus point (used for object-position in every frame) and its close-up crop. `build.py --images` re-cuts every photo and applies one house grade so stand-ins from different shoots sit together.
- **One night band** on the home page carries the gold sequin sky; the sequin "2010" sits in the house section.
- `identity.html` presents the logo, its motion, the three palettes and the applications (bag, tag, cards, tissue, Instagram grid).

## What lives where

| File | What it is | Shopify later |
|---|---|---|
| `data/products.json` | 22 pieces, each named after something in the sky | Products |
| `data/site.json` | Founding year, contact, currencies, delivery times, stitching prices, credits | Theme settings, Markets |
| `templates/base.html` | Header, nav preview, menu, search, bag drawer, footer | `layout/theme.liquid` + header/footer sections |
| `templates/index.html` | Home page | `templates/index.json` sections |
| `templates/collection.html` | Category pages with filters | `templates/collection.json` |
| `templates/product.html` | Product page, stitching options, sizes | `templates/product.json` |
| `templates/bridal.html`, `story.html`, `pages/*` | Bridal booking, story, help pages | Page templates |
| `static/js/sequins.js` | The sequin sky and the sequin "2010" | Theme asset, unchanged |
| `data/images.json` | Focus point and close-up crop per photo | Image focal points in Shopify |
| `templates/partials/logo.html` | Lockup, stacked mark, seal (generated by `build_logo.py`) | Snippets |
| `static/js/logo.js` | Logo writing, intro curtain, twinkle | Theme asset |
| `templates/identity.html` | Brand identity presentation | Not a store page |
